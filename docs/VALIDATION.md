## 0.5.4：按黑区占比过滤零散黑点（本地真机测试）

2026-10-30 在黑位保护前增加可调占比过滤，默认开启、阈值 15%，网页“画面与颜色 → 亮度与柔化”可关闭或调整 1%–50%。按已分配灯珠的原始近黑程度加权计算占比，不统计未分配灯珠；低占比时使用物理走线附近的原始有效颜色，接近占比上限及暗部边界时平滑减弱补色。C 字形不跨缺口，闭合灯带可首尾寻找邻色；全黑或没有有效邻色时不补色。

- 五组网页测试、21 套主机 Java 合约通过。新增算法 336 项检查覆盖完整映射/校正/柔化链路、两档采样、首次黑点补色、暗部阈值波动、占比连续变化、大片与全黑、暗彩邻色、C 形开口/闭环、稀疏灯号、零亮度、禁用回退及帧隔离；原有 4,064 项黑位检查继续通过。配置检查新增 24 项，自动保存现有 21 组行为通过。
- 非调试 versionCode 14 静默覆盖安装后，保存的完整配置、总开关、USB-C 输入及外部信号前台保持相等，守护连接与新鲜采样正常；旧配置未被补写默认字段。
- 真实后台依次核验关闭过滤、40% 阈值、1% 阈值，并核对保存/应用指纹。40% 测试时实际占比约 8.2%，11 颗灯获得补色；1% 时约 8.4%，补色灯数为 0。结束恢复原完整 JSON，默认 15% 下约 8.3%、11 颗补色。运行期间画面变化，因此这些比例来自各自时刻，不作为同一帧的对照。
- APK v2/v3 签名通过，安装包与交付测试包 SHA256 一致，六份网页资源与源码相同。浏览器检查新增控件与现有开关/滑条对齐，无横向溢出。

补色指标确认算法已在实际采样链生效，不代替使用者对电影闪烁和灯带观感的验收；本次未重新验收全部输入、HDR/DRM、待机恢复或长期运行。0.5.4 当前为本地安装测试版。

## 0.5.2：输入条件、电源恢复与静默唤醒（本地真机测试）

目标设备：Redmi G Pro 32U 2026 / Android 14。2026-10-30 覆盖安装非调试版 versionCode 12，当前使用 USB-C、细腻采样、接口筛选和条件不满足时关灯。

- 静默覆盖更新后，系统自动绑定并恢复采集；前后前台均为 `com.xiaomi.mitv.tvplayer/.ExternalSourceActivity`，输入源仍为 USB-C，没有启动 XH光流主界面，完整配置相等。
- 临时从允许接口列表排除当前 USB-C，真实 WLED 电源回读确认 OFF，实时输入已停止。结束 XH光流进程后由系统恢复，仍保持排除与关灯状态，前台 Activity 和输入源不变。
- 在存在待恢复记录时关闭总开关、恢复原接口设置，再重建进程：只恢复网页，没有自动开灯；明确重新开启总开关后，WLED ON 回读成功，新鲜取色与发送恢复。结束时原完整配置与开关状态相等。
- 通过 ADB 发送休眠按键，实际显示状态进入 OFF，WLED 关灯回读成功；睡眠期间结束并重建本包进程，恢复记录保留。约 8 秒后发送唤醒按键，WLED ON 回读成功，新鲜取色和发送恢复；前台、输入源与配置不变。此项验证了当前 USB-C 下的实际待机流程，未重新逐个测试所有物理端口。
- 五组网页测试、19 套主机 Java 合约通过。新增初始化重试 53 项、跨进程灯控状态 108 项及持久化提交 47 项检查；OFF 前必须真正成功落盘，即使失败提交已更新 SharedPreferences 内存，也不能据此关灯。后台恢复原有 68 项检查继续通过。

尚未完成多日运行、所有固件/端口、断电开机及 HDR/DRM 的重新验收。WLED 电源的 HTTP 回读与实际 DDP 发送状态不代替逐颗灯珠的视觉验收。

## 0.5.1：系统绑定恢复（本地真机测试）

目标设备：Redmi G Pro 32U 2026 / Android 14。2026-10-30 读取到此前数次进程退出均为 `USER REQUESTED / FORCE STOP`，原辅助功能守护不在授权列表，普通前台服务也未被固件登记。本次使用相同签名覆盖安装 versionCode 11，安装前后完整配置相等。

- 增加独立通知监听服务绑定，系统侧确认本组件同时出现在 Allowed 和 Live 列表，应用返回 `revivalAuthorized=true`、`revivalConnected=true`、`keepAliveMode=revival`。不依赖恢复已被移除的无障碍授权。
- 在离开主界面后，对本包执行 `am force-stop`，无需重新打开 Activity，观察到新 PID，最终包约 2.18 秒后重新出现新鲜取色及发送状态。系统恢复后也登记了前台服务。
- 关闭总开关后重复结束本包，最终包约 0.75 秒后网页后台恢复，`enabled=false`、`running=false`，未自行开启灯光。
- 在系统恢复的会话中关闭“开机运行”，网页保持可用；再次结束进程后，系统仍绑定恢复服务，但配置后台与取色不再自动运行。手动打开后网页正常可用，总开关仍关闭。
- 撤销恢复授权后，实际状态变为未授权、未连接，系统列表不再有本组件；观察期间没有自行恢复授权。测试后重新开启保护，恢复原总开关与开机设置，保存的完整配置相等。
- 全部 5 组网页测试及 16 套主机 Java 合约通过；新增 68 项恢复检查覆盖当前宿主、关闭后台、撤销授权、过期回调、关闭开机恢复保留现有会话及最多三次尝试。每次本地绑定最多等待 5 秒，不依赖无限重试。

上述时间是局域网轮询首次观察到的结果，包含请求与初始化耗时。这里模拟的是该固件上已观察到的强停路径，不代表所有 Android 设备都允许强行停止后的系统重绑；应用没有清除 stopped 标记或主动恢复已撤销授权。尚需长期运行与实际遥控待机/唤醒观察，不能把一次进程恢复测试等同长期保活验收。

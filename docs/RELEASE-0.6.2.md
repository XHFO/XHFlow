# XH光流 0.6.2

本版改进 Yeelight 显示器挂灯 Pro 的前向主灯控制：手动调节优先，不同场景间以约 5 秒柔和过渡。包含此前本地 0.6.1 的手动优先修复。

## 更新

- 手动改变主灯亮度或色温后，停止自动调节这两项，直到确认切换到另一个输入接口。配置应用、网络重连、休眠唤醒及后台重建保留手动优先；主灯开关继续遵循场景。
- 主灯亮度、色温与场景开关采用原生约 5 秒渐变。过渡期间保留最新目标，完成并回读稳定后再调节，避免连续指令打断渐变。
- 不将自身渐变的中间值提前判为手动操作；无法可靠读取主灯状态时，暂缓亮度和色温的自动调节。
- 游戏模式开启画面亮度联动时，直接使用当前有效画面的目标亮度，避免先跳到预设亮度再调整。
- 网页显示主灯手动优先、柔和过渡及状态读取情况。WLED 与挂灯背光保持原有跟色响应。

## 升级

- **从公开的 0.6.0 升级**：签名不同，不能直接覆盖。请先在网页导出配置 JSON，再卸载旧版、安装本版、导入配置，并重新开启需要的系统后台授权。卸载会清除应用私有数据，包括手动优先状态；配置 JSON 不包含该状态和系统授权。
- 从使用相同签名的本地 0.6.1 升级，可直接覆盖并保留配置与手动优先状态。
- 新安装仍需完成设备配置；已关闭的总开关不会因更新或后台恢复而自行开启。

## 验证

五组网页测试与 29 套主机 Java 契约测试通过；新过渡契约包含 182 项检查。非调试 APK 的 v2/v3 签名通过验证，六份网页资源与源码一致。

0.6.2 已在 Redmi G Pro 32U 2026 上静默安装：完整配置、保存及活动指纹、后台授权、手动优先状态均保留，当前输入源与前台应用未改变。后台与挂灯状态回读恢复后连续观察 33 秒正常；使用者随后确认该版效果符合预期。

这些结果不代表所有挂灯固件、输入接口或长期运行均已验证。精确渐变时长未独立测量。状态检测细节见 [挂灯手动优先说明](YEELIGHT-MANUAL-PRIORITY.md)。

# XH光流 0.6.0

0.6.0 增加第二路灯光输出与场景编排，并重做取色稳定性。

## 新增

- **Yeelight 显示器挂灯 Pro 氛围灯**：局域网直连（SSDP 发现、UDP 55444 会话令牌），不需要 Razer Chroma 或 Yeelight Chroma Connector。取屏幕顶部取色范围，按中心加权收敛为单色。
- **氛围灯工作模式**：办公场景切换为 4000K 照明白光（`bg_set_ct_abx`），观影与游戏保持屏幕同色，夜间与全关熄灭。
- **挂灯与灯带共用开关条件**：同步暂停、停止、休眠、接口不符时一并收电，恢复时重新点亮；前向主灯由场景决定，不随画面闪烁。
- **智能场景**：每个信号源可绑定观影 / 游戏 / 办公 / 夜间 / 全关，决定灯带、氛围灯、主灯三路输出。
- **排布画布中的挂灯灯棒**：直线灯条可选中、拖动、按实际宽度校准，标签实时显示当前平均色。

## 改进

- **取色稳像**：3 帧中值滤波 + 1 级死区，供应商取色服务偶发的单帧异常值不再传到灯上。
- **黑位上限平滑**：暗场里 ±1 抖动不再让输出在 4 与 7 级之间跳变；纯黑仍立即清零。
- **非对称平滑与渐暗**：上升快、下降慢；亮转黑按“渐暗时长”（默认 2 秒，可调 0–5 秒）线性压暗。
- **抗频闪**：黑域判断带迟滞（进入 8、退出 14）与保持时间，输出另有速率上限（每秒最多升 1400、降 550 级）。
- **场景下拉菜单**不再被后台轮询重建，展开后可直接选择。

## 限制

- 电视/显示器自带的底部氛围灯由厂商私有服务驱动，SELinux 只允许系统域访问，本版本不控制；需要 root 或系统签名应用。
- 挂灯氛围灯是单色灯，横向渐变仍由 WLED 灯带表达。
- 局域网 HTTP 与 UDP 无加密，配置地址含访问凭据，请只在可信局域网使用。

## 升级说明

- 本版改用新的本地测试签名；从 0.5.4 覆盖安装会因签名不一致失败，需要先卸载再用网页导出的配置恢复。发布正式安装包时应使用项目原有私钥签名。

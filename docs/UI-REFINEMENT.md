# 界面调整说明

本轮参考用户提供的 [圆角与间距规则](https://x.com/Kubai087/status/2115469767650021796)：同层统一，嵌套圆角按“外圆角减内距”计算，圆角、内距与间距使用 4 单位网格；胶囊和圆形保留全圆。延续 XH_Lab 的浅色、紫色渐变与深色配色。

## 圆角变化

网页单位为 CSS px。外层与内层使用变量推导，避免每个组件单独设置近似值。

| 网页元素 | 原值 → 当前值 |
| --- | --- |
| 主功能面板 | 22 → 40 |
| 面板内距 | 22/25 等 → 24 |
| 内层设置卡片、校准画布 | 新增 / 原 18 → 16，按 40−24 计算 |
| 输入框与普通矩形控件 | 12 或全圆 → 8，按 16−8 计算 |
| 采样档位选择器 / 内部选项 | 全圆 → 16 / 12，内缩 4 |
| 保存状态栏 | 独立新增 24 |
| 零散内距与间距 | 3/5/9/10/17 等 → 4 的倍数 |
| 正背面等胶囊选择器、状态标签、开关轨道与圆点 | 保持全圆 |

640 px 及以下窗口将主面板圆角与内距调整为 32 / 16，内部仍保持 16 / 8 的推导关系。

电视单位为设计 dp，随整页布局同比缩放。主面板、背景、边缘彩虹开孔和内容裁切共享路径。

| 电视元素 | 原值 → 当前值 |
| --- | --- |
| 主面板 | 28 → 32 |
| 同层卡片 | 22 → 20，按 32−12 计算 |
| 二维码框 | 14 → 8，按 20−12 计算 |
| 总开关容器 | 新增 8 |
| 主面板内缩 | 保持 12 |
| 卡片内距 | 10/11/14 等 → 12 |
| 二维码内距 | 3 → 4 |
| 按钮内距 | 10/7 → 12/8 |
| 零散间距 | 3/10/14 → 4/8/12 |
| 后台守护、返回画面按钮 | 全圆 → 8，与总开关容器一致 |

电视主面板距屏幕四边使用相同像素留白：`round(min(屏幕宽, 屏幕高) × 10%)`。例如 1920×1080 为四边各 108 px，面板为 1704×864 px；内部仍保留 12 dp 设计内缩，并据实际可用空间统一缩放。外圈彩虹使用同一面板边界。

## 连续圆角与兼容

网页使用 `@supports (corner-shape: superellipse(1.25))` 渐进增强；支持时使用连续圆角，不支持时使用同一半径体系的普通 `border-radius`。不能将规则存在于源码等同于 Safari、Firefox 或所有 Android WebView 均支持；需在目标浏览器实际检查。胶囊、开关轨道与圆形部件保持 `round`。

Android 使用每角两段三次 Bézier 对 `superellipse(1.25)` 作 G2 连续近似，让直边与角的切线及曲率连续。它不是浏览器原生 CSS 曲线的精确复现。几何测试检查的是共享路径算法，设备截图仍需验证实际描边、裁切和阴影。

## 信息归属与行为

电视保留固定左右布局：左侧为说明与真实运行状态，右侧为二维码、唯一总开关和返回画面动作。两侧标题与副标题使用一致的字号、内缩和基线；二维码与地址在标题和底部操作之间的空余区域作为一组视觉居中。管理后台守护、总开关和返回画面均为 44 dp 设计高度并底部对齐，左右操作说明使用相同高度；右侧总开关与返回画面并排。总开关固定显示“XH光流”，52×32 dp 胶囊轨道配圆形滑块，以强调色表示开启、灰色表示关闭；保留原生 Switch 的遥控、触控与可访问性语义，不在轨道内挤入开关文字。遥控焦点使用外描边，不放大控件，避免影响底线或将大块高亮误认为开启状态。后台守护是可选系统授权入口，显示实际授权与连接状态，不作为第二个灯控开关。打开应用确保网页后台运行；关闭总开关暂停灯控，网页继续可用；再次打开应用保留用户的关闭意图。

电视投影只保留在最外层主面板：沿共享连续圆角轮廓投下柔和外阴影，使白色面板悬浮于彩虹背景。内部卡片、按钮和开关的 elevation / translationZ 为零，依靠底色、边线和焦点描边区分层级，避免叠加系统阴影。

网页顶部统一显示自动保存状态与配置文件工具，其后依次为设备与控制、画面与颜色、灯带排布、运行条件。采样档位、取色缩进和黑边归入画面采样；亮度与柔化归入灯光输出；饱和度、增益、偏移、Gamma 和 RGB 增益归入高级颜色校正；开机恢复及后台状态归入运行条件。

自动保存只提交完整有效的设置。连续拖动时延后提交，断线时保留有效调整，多页面修改冲突时暂停并让用户选择。保存与应用状态分开显示；保存不会开启已关闭的总开关。实时画布继续展示原始边缘取色与当前排布映射，不将亮度、柔化或颜色校正伪装成真实灯光预览。

## 新版截图与验收清单

公开电视截图已更新为 0.5.0 真机界面，网页截图为本地演示。验证结果见 [验证记录](VALIDATION.md)，后续跨设备检查可沿用：

- 电脑与手机宽度下的网页明暗两种主题，检查折叠层级、固定保存栏、画布和键盘焦点。
- 网页自动保存、失败重试、断线重连与冲突选择状态；确认无效输入不会覆盖上次有效配置。
- 电视主界面及总开关、后台守护、返回画面三个控件的聚焦状态；默认字号与 1.3 倍系统字体。
- 电视总开关关闭后重新打开应用，确认灯控保持关闭且网页可用；开启后确认读取保存配置、实际接口条件和灯光输出。

公开截图应使用合成设备配置，或以完全不透明遮盖隐藏真实二维码、访问 token、完整配对 URL 和真实局域网地址。未遮盖的原图、设备配置和签名资料不加入公开仓库。

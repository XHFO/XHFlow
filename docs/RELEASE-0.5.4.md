# XH光流 0.5.4 测试版

本版汇总 0.5.1–0.5.4 的后台恢复与灯光算法改进，适配目标为 **Redmi G Pro 32U 2026 / Android 14**，Android versionCode 为 14。

## 变化

- **静默恢复后台**：可选系统恢复保护，在系统重新绑定后恢复网页与此前开启的同步，保持当前前台画面和输入源。总开关关闭时只恢复网页；关闭开机运行后不自动重建工作会话。
- **恢复灯控电源**：保存因休眠或接口条件关灯后的恢复记录，进程重建后仍按总开关、亮屏和接口条件决定是否恢复。WLED 临时连接或电源请求失败后按退避间隔重试。
- **黑位保护**：纯黑画面输出为 0，未补色近黑区域输出为 0–4；颜色校正与柔化不会重新抬亮这些黑区。
- **零散黑点过滤**：默认开启，低于占比阈值时使用走线邻近的有效颜色，减少灯光反复明灭。默认阈值 15%，网页可调 1%–50%；接近阈值时平滑退出补色，大面积黑场保持黑位。C 字形不跨开口补色。
- **网页配置**：保留有效修改自动保存、已开启同步时安全应用和指纹回读；新增过滤开关与占比滑条，更新电视端及 WebUI 截图。

## 验证

五组网页测试、21 套主机 Java 合约通过，包括新增的 336 项占比过滤检查和 4,064 项黑位检查。真机覆盖安装保留完整配置、总开关、USB-C 输入和前台画面；过滤开关及高低阈值均经保存/应用指纹与实际补色指标核验。此前 0.5.2 已在当前 USB-C 场景验证休眠关灯、进程重建和唤醒恢复。

补色与 UDP 发送指标不代替灯带观感验收。尚未完成多日稳定性、全部输入端口、断电开机、其他机型/固件和 HDR/DRM 的完整验证；后台恢复仍受 Android 与厂商策略影响。

## 安装与说明

下载本次 Release 的 APK，使用相同签名覆盖升级可保留配置；建议先在网页导出 JSON 备份。仍需在电视系统中授权可选的后台恢复保护，应用不会自行授予或恢复已撤销授权。
